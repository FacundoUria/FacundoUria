### 🚀 Proyecto Principal Destacado: Ecosistema GreenFit

**GreenFit** es una plataforma integral de gestión tecnológica y entrenamiento para gimnasios y centros deportivos. Está diseñada bajo una arquitectura modular y desacoplada para garantizar máxima velocidad, estabilidad y seguridad.

    #### 📌 Módulos y Repositorios del Ecosistema:

* **💻 Admin Dashboard:** Panel de control centralizado para la administración del gimnasio.
  * **Características:** Gestión de socios, control de cuotas/vencimientos, agenda y cupos de clases en tiempo real, configuración de packs/precios y creador de rutinas.
  * **Repositorio:** [`GreenfitAdminDashboard`](https://github.com/FacundoUria/GreenfitAdminDashboard)

* **📱 PWA para Socios:** Aplicación web progresiva móvil orientada a la experiencia del usuario.
  * **Características:** Reserva interactiva de clases, estado de cuota, visualización de rutinas con contador de progreso, métricas de ejercicios y links a videos explicativos.
  * **Repositorio:** [`GREENFIT-APP`](https://github.com/FacundoUria/GREENFIT-APP)
